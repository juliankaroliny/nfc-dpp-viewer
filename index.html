Private by design. Tags are decoded entirely in your browser. This page has no backend and no analytics, and its Content-Security-Policy blocks every network request, so scanned data can't leave your device.

Which devices are supported?
  • Android + Chrome 89 or newer: supported (needs HTTPS and NFC switched on).
  • iPhone / iPad: not supported. Apple doesn't expose NFC to websites in any iOS browser.
  • Desktop browsers: not supported.

Web NFC gives the page each record's payload already parsed. For URL records the prefix byte is already expanded, and for text records the status byte and language code are removed. So the hex view shows the payload, not the raw bytes on the chip.
